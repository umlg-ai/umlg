# Объект без класса

Класс `LegacyWorker` удалили из проекта очереди, но `legacy-worker-1` остался
в работающем развёртывании. Это случай `orphan-object` из
[таблицы расхождений](../../spec/01-worlds.md#8-расхождение-drift).

В [модели](model.json) связь `drift` указывает от компонента `JobQueue` на
работающий объект. Компонент показывает, где искать расхождение. Связи
`materializes` у объекта нет. В [раскладке](layout.json) его обозначает красный
маркер с подписью `drift: class missing`.

Команда `make validate` проходит и выводит предупреждение о том, что у
`r.obj.legacy-worker-1` отсутствует связь `materializes`.

**Почему объект существует, а класса нет?**

Удаление класса из замысла само по себе не останавливает экземпляр в уже
работающем развёртывании. R-мир хранит этот факт, а `drift` отмечает расхождение.
