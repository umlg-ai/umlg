# Prompt — Skeptic / Red Team

Ты скептик. Твоя задача — попытаться закрыть UMLG. Если не выйдет, сформулируй, что именно его держит.

Прочитай:

- `README.md`
- `ROADMAP.md`
- `spec/00-manifest.md`
- `docs/video/hello-triangle-demo.md`
- `docs/review/checklists/skeptic.md`

Ответь:

1. Зачем это, если есть UML и 2D-схемы?
2. Что даёт 3D, чего не даёт 2D + анимация?
3. Оправдывает ли второй мир удвоение сложности?
4. Почему это не игра и не «3D ради 3D»?
5. Что сломается на 50 классах и 1000 объектов?
6. Кто будет делать контент через год?
7. Какой результат теста опровергнет проект?
8. Какое одно изменение сильнее всего повысит шансы?

Формат — по `docs/review/protocol.md`. Обязательно:

- verdict;
- findings P0–P3 с evidence;
- strongest counterargument;
- falsification test;
- confidence.

Не редактируй файлы. Не будь вежливым за счёт честности.
