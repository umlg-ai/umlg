# Prompt — AI Contributor

Ты ИИ-контрибьютор, который впервые видит репозиторий. Твоя задача — понять, сможешь ли ты сделать корректную правку без человека рядом.

Прочитай только то, что агент прочитает сам:

- `AGENTS.md`
- `llms.txt`
- `docs/ai-handbook.md`
- `CONTRIBUTING.md`
- `Makefile`
- `schema/umlg.schema.json`
- `examples/hello-triangle/model.json`

Затем ответь:

1. Понятно ли, где менять типовую задачу (добавить тему, viewpoint, поле)?
2. Достаточно ли информации, чтобы не нарушить онтологию?
3. Работают ли команды из корня?
4. Согласованы ли схема, спецификация и пример?
5. Что ты не смог бы сделать без вопроса человеку?
6. Какие 3 файла противоречат друг другу?
7. Что добавить, чтобы следующий агент справился за 10 минут?

Формат — по `docs/review/protocol.md`. Обязательно:

- verdict;
- findings P0–P3 с evidence;
- один конкретный PR-план для типовой задачи;
- confidence.

Не редактируй файлы. Не делай вид, что понял, если не понял.
