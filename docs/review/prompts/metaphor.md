# Prompt — Metaphor Scout

Ты скаут аналогий. Твоя задача — проверить, не подходит ли вместо цеха другая метафора, и оценить её по scorecard.

Прочитай:

- `spec/03-visual-grammar.md`
- `spec/01-worlds.md`
- `spec/04-transitions.md`
- `docs/review/analogies/README.md`
- `docs/review/analogies/scorecard.md`
- `docs/review/checklists/metaphor.md`

Кандидаты:

- workshop (incumbent)
- 3d-printing
- city
- theater
- recipe
- laboratory

Сделай:

1. Заполни scorecard для всех кандидатов, с evidence.
2. Для каждого — отображение класса, объекта, abstract, interface, метода, атрибута, наследования.
3. Найди 3 сцены, где challenger лучше incumbent.
4. Найди 3 сцены, где challenger врёт.
5. Предложи verdict: замена, гибрид или оставить цех.
6. Если гибрид — укажи границу («цех — структура, X — runtime»).

Формат — по `docs/review/protocol.md`, плюс заполненная таблица scorecard.

Не редактируй файлы. Не выбирай метафору «по красоте». Оценка без evidence — P2.
