# Checklist — Learning Designer

Проверяй, что новичок действительно учится, а не любуется сценой.

## Self-check

- [ ] Вопросы отвечаются из модели, без внешних знаний.
- [ ] Эталонные ответы не противоречат спецификации.
- [ ] Вопросы проверяют понимание, а не память.
- [ ] Есть вопросы на различение (класс/объект, abstract/deprecated).
- [ ] Есть вопрос «что будет, если...».
- [ ] 5–7 вопросов, не больше.

## Нагрузка

- [ ] На первом экране не больше 7±2 сущностей.
- [ ] Термины определены до использования.
- [ ] Story mode не скрывает формальные данные навсегда.
- [ ] Architecture mode доступен сразу.
- [ ] Нет обязательного тура.

## Задания

- [ ] 2–3 упражнения с проверяемым результатом.
- [ ] Упражнения не требуют новых сущностей ядра.
- [ ] Ошибка упражнения объясняет, а не наказывает.

## Красные флаги

- ответ на self-check звучит как реклама;
- вопрос требует знания, которого нет в теме;
- NPC объясняет больше, чем модель содержит;
- «просто посмотри на красоту» вместо задачи.
