# Checklist — AI Contributor

Проверяй, что агент может войти в репозиторий и сделать корректную правку без человека рядом.

## Вход

- [ ] `AGENTS.md` существует и читается первым.
- [ ] `llms.txt` даёт плоскую карту.
- [ ] `docs/ai-handbook.md` объясняет онтологию и ошибки.
- [ ] Команды валидации работают из корня.
- [ ] Нет шагов, требующих «спросить автора».

## Правка

- [ ] Понятно, какой файл менять для типовой задачи.
- [ ] Схема и спецификация согласованы.
- [ ] Пример можно скопировать как шаблон.
- [ ] Валидатор ловит типовые ошибки.
- [ ] Definition of Done проверяем.

## Восстановление

- [ ] Ошибка валидатора объясняет, что делать.
- [ ] Есть known limitations.
- [ ] Есть issue-шаблоны для RFC и темы.
- [ ] Решения зафиксированы, а не в переписке.

## Красные флаги

- правила только в чате;
- «посмотри, как в другом файле» без ссылки;
- несовпадение схемы и примера;
- команда, которая работает только на машине автора.
