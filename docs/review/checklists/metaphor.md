# Checklist — Metaphor Scout

Твоя задача — не защищать текущую метафору, а найти лучшую, которая объясняет лучше.

## Отображение

- [ ] Класс → ? (тип, а не место)
- [ ] Объект → ? (экземпляр, а не тип)
- [ ] Абстрактный класс → ? (не «мёртвый»)
- [ ] Интерфейс → ? (контракт без тела)
- [ ] Метод → ? (операция)
- [ ] Атрибут → ? (состояние)
- [ ] Наследование → ? (расширение/материализация)
- [ ] Композиция/агрегация → ?
- [ ] Связь → ?
- [ ] Runtime → ?
- [ ] Drift → ?

## Коллизии

- [ ] Абстрактный ≠ deprecated ≠ unused ≠ deleted ≠ mock ≠ proxy.
- [ ] Тип ≠ экземпляр.
- [ ] Контракт ≠ место.
- [ ] Данные ≠ поведение.

## Критерии

- [ ] Семантическая точность.
- [ ] Различимость состояний.
- [ ] Обучаемость без подсказок.
- [ ] Необходимость 3D (глубина что-то кодирует).
- [ ] Масштабируемость до 1000 объектов.
- [ ] Расширяемость (generic, nested, singleton, enum, lambda, record).
- [ ] Культурная нейтральность.
- [ ] Стоимость миграции.
- [ ] Тестируемость.

## Решение

- [ ] Scorecard заполнен.
- [ ] Challenger сравнивается с incumbent, а не с пустотой.
- [ ] Есть план миграции.
- [ ] Нет тихой замены метафоры.
