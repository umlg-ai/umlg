# Checklist — Visual Grammar

Проверяй, что метафора читается и не врёт.

## Различение

- [ ] Класс и объект различимы без подписи: проект vs работающий цех.
- [ ] `abstract` не путается с `deprecated`, `unused`, `deleted`, `mock`, `proxy`, `sealed`.
- [ ] Интерфейс — контрактный узел, не цех.
- [ ] Абстрактный метод — пустой слот, а не удалённый станок.
- [ ] Конкретный метод в абстрактном классе — работает, но призрачный.
- [ ] Статический член — solid и вне цеха.

## Связи

- [ ] Связь задаётся линией, а не положением.
- [ ] Кратность — текст, не толщина.
- [ ] Цвет кодирует только состояние.
- [ ] Наследование читается как материализация, а не как «дорога».
- [ ] Композиция и агрегация различимы.

## NPC

- [ ] NPC не кодируют тип, кратность, видимость.
- [ ] Точные данные доступны в инспекторе.
- [ ] Поведение NPC выводится из модели.
- [ ] NPC можно отключить.

## Масштаб и LOD

- [ ] LOD не меняет семантику.
- [ ] 1000 объектов агрегируются, а не превращаются в 1000 NPC.
- [ ] На L0 связи не исчезают бесследно.

## Красные флаги

- один полупрозрачный вид означает пять состояний;
- декоративная анимация без смысла;
- «важность» через размер;
- ручная анимация под каждый класс.
