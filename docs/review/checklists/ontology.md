# Checklist — Ontologist

Проверяй, что модель не врёт о том, что существует.

## Инварианты

- [ ] У каждого элемента есть `world` и допустимый для мира `kind`.
- [ ] `abstractClass` не является источником `materializes`.
- [ ] У каждого R `object` ровно один `materializes` (или явный `drift`).
- [ ] `implements` не пересекает границу M/R.
- [ ] `materializes` идёт только M → R.
- [ ] `observes` не меняет модель.
- [ ] `drift` показан явно, а не замалчивается.
- [ ] Ни один элемент не существует в двух мирах без связи.

## Источник истины

- [ ] Тип, сигнатура, инвариант — из M.
- [ ] Наличие экземпляра, состояние, метрика — из R.
- [ ] Соответствие «объект ↔ класс» — из связи.
- [ ] Нет попытки «исправить» R переписыванием M.

## Присутствие

- [ ] Одно присутствие, один мир.
- [ ] Второй мир не рендерится.
- [ ] Метаданные двойника не превращаются в превью.

## Расширяемость

- [ ] Новый мир (S, физический) не ломает правило присутствия.
- [ ] Новый `kind` не дублирует существующий.
- [ ] ID стабильны и не переиспользуются.

## Красные флаги

- объект без класса, объявленный «нормальным»;
- абстрактный класс с объектом;
- `inheritance` в R-мире;
- `flow` в M-мире;
- layout, влияющий на семантику.
