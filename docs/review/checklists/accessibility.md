# Checklist — Accessibility

Проверяй, что язык доступен, а не только красив.

## Движение и вспышки

- [ ] `reduced motion` отключает вспышки, FOV-дыхание, длинные эффекты.
- [ ] Переход при `reduced motion` мгновенный, но смысл сохранён.
- [ ] Нет мерцания > 3 Гц.
- [ ] Нет принудительной тряски камеры.

## Восприятие

- [ ] Цвет не единственный канал смысла.
- [ ] Контраст текста ≥ 4.5:1.
- [ ] Направление перехода дублируется текстом и звуком/haptic.
- [ ] Шрифт читаем на 1080p и в VR.
- [ ] Субтитры для видео.

## Ввод

- [ ] Удержание имеет альтернативу (toggle/подтверждение).
- [ ] Клавиши переназначаемы.
- [ ] VR-жест не срабатывает случайно.
- [ ] Переход блокируется во время ввода текста.

## Screen reader

- [ ] Объявляется мир, фокус, результат перехода.
- [ ] Инспектор доступен без 3D.
- [ ] Порядок фокуса логичен.

## Красные флаги

- «просто не используйте reduced motion»;
- смысл только в цвете;
- звук обязателен;
- 3D — единственный способ получить информацию.
