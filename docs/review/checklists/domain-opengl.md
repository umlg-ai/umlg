# Checklist — Domain Expert (OpenGL)

Проверяй предметную корректность, а не красоту.

## Hello Triangle

- [ ] `VBO` содержит 9 float: три вершины по три координаты.
- [ ] `VAO` хранит конфигурацию атрибутов, а не данные.
- [ ] `EBO` присутствует, но не используется в draw — это объяснено.
- [ ] `ShaderProgram` — результат линковки, а не просто два файла.
- [ ] `VertexShader` и `FragmentShader` — конкретные подклассы `Shader`.
- [ ] `glDrawArrays(GL_TRIANGLES, 0, 3)` соответствует трём вершинам.
- [ ] Стадии идут в порядке: vertex → primitive → raster → fragment → output.
- [ ] `DefaultFramebuffer#0` — цель вывода по умолчанию.

## Инварианты перед draw

- [ ] программа слинкована и активна;
- [ ] VAO привязан;
- [ ] атрибут 0 включён;
- [ ] VBO привязан к VAO и содержит данные.

## M/R

- [ ] M описывает типы и контракты, R — факты.
- [ ] Нет ложного утверждения, что у `Shader` есть R-двойник.
- [ ] CPU/GPU — акторы R, а не классы M.

## Красные флаги

- «VAO хранит вершины»;
- «EBO обязателен для glDrawArrays»;
- «шейдер компилируется в программу» без линковки;
- стадии в неверном порядке;
- версия OpenGL не указана, а поведение зависит от версии.
