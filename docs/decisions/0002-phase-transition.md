# 0002 — Переход как фазовый сдвиг

- Статус: accepted
- Дата: 2026-11-12
- Контекст: v0.1

## Решение

Переход между M и R — не портал и не телепорт, а **смена агрегатного состояния мира вокруг наблюдателя**.

- `M → R` — кристаллизация.
- `R → M` — сублимация.
- Переход доступен в любой точке и в любой момент.
- Второй мир не рендерится.
- Камера сохраняет позицию и ориентацию.

## Причины

1. Портал привязан к месту, а требование — «в любое время в любом месте».
2. Привязка к наблюдателю сохраняет пространственную память.
3. Асимметричные эффекты читаются без текста.
4. Правило масштабируется на будущие миры (S, физический).

## Параметры

| Параметр | Значение |
|---|---:|
| удержание desktop | 200 мс |
| удержание VR | 250 мс |
| intent | 0.15 с |
| phase | 0.55 с |
| arrival | 0.30 с |
| cooldown | 500 мс |
| skip после | 0.3 с |

## Следствия

- Нужны `phaseSignature` у каждого мира.
- Нужен `reduced motion` с мгновенной сменой.
- HUD показывает только идентичность двойника, не сцену.
- Порталы, мембраны и crossfade запрещены.

## Альтернативы

| Альтернатива | Почему отклонена |
|---|---|
| Портал в фиксированной точке | нарушает «в любом месте» |
| Crossfade между мирами | показывает второй мир |
| Мгновенная смена без эффекта | теряется направление и ощущение онтологии |
| Телепорт камеры | ломает пространственную память |
