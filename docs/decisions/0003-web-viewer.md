# 0003 — Web-вьюер первым, Godot позже

- Статус: accepted
- Дата: 2026-11-12
- Контекст: v0.1

## Решение

Референсный вьюер v0.1 — web (three.js + TypeScript). Godot-плагин и собственный Vulkan-бэкенд — возможные расширения, но не первые.

## Причины

1. GitHub + ссылка: «открыл и посмотрел» без установки.
2. Кроссплатформенность и быстрый цикл итераций.
3. Проще тестировать на 5–8 людях.
4. Ядро всё равно engine-agnostic: модель, viewpoint и переходы не зависят от рендерера.

## Почему не Godot сейчас

- экспорт под несколько платформ;
- тяжелее делиться;
- для v0.1 не даёт преимуществ.

## Почему не «чистый Vulkan»

- Vulkan — API рендеринга, а не движок;
- пришлось бы писать окно, ввод, камеру, пикинг, 3D-текст, UI, ассеты, LOD;
- это отдельный проект, который съест время у языка.

Vulkan имеет смысл как **тема курса** (визуализировать Vulkan), а не как способ сделать вьюер.

## Следствия

- `viewer/` — web-приложение.
- Core отделён от рендера.
- Godot-плагин — M5, не раньше.
- Экспорт glTF/USDZ — возможное расширение.
