# Changelog

Все заметные изменения UMLG. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.1.0] — draft

### Added

- Манифест UMLG v0.1: миры M/R, viewpoint-контракты, политика сложности.
- Онтология миров: элементы, связи, материализация, drift, инварианты.
- Визуальная грамматика: цех, призрак, NPC, LOD, визуальные переменные.
- Спецификация фазового перехода: кристаллизация и сублимация, тайминги, доступность.
- Сериализация: `model.json` + `layout.json`, стабильные ID, провенанс.
- JSON Schema 2020-12 для модели и layout.
- Пример `Hello Triangle`: 35 элементов, 32 связи, 14 межмировых ссылок.
- Семантический валидатор `tools/validate.py`.
- Проверка ссылок `tools/check_links.py`.
- Topic Card `Hello Triangle` и матрица курса.
- `AGENTS.md`, `docs/ai-handbook.md`, `llms.txt` для ИИ-контрибьюторов.
- Записи решений: два мира, фазовый переход, web-вьюер.
- План видео-демо `Hello Triangle`.

### Known limitations

- Вьюер не реализован.
- S-мир (код/шейдеры) зарезервирован, но отсутствует.
- Нет импорта/экспорта UML/XMI.
- Нет runtime-метрик и drift-примеров.
- Видео не записано.
