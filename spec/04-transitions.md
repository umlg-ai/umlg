# 04 — Переходы между мирами

## 1. Основной принцип

> Переход — не портал и не телепорт. Это смена агрегатного состояния мира вокруг наблюдателя.

Портал привязан к месту. Фазовый переход привязан к человеку. Поэтому он доступен **в любой точке и в любой момент**.

Следствия:

- не нужны шлюзы, двери и точки входа;
- другой мир **никогда не рендерится** — ни сквозь мембрану, ни как crossfade, ни как превью;
- камера не делает cut: позиция и ориентация сохраняются;
- меняется не сцена, а законы текущего мира.

## 2. Что именно меняется

| Аспект | M-мир | R-мир |
|---|---|---|
| Материал | голограмма, чертёж | solid, металл, бетон |
| Свет | холодный, рассеянный | тёплый, направленный |
| Тени | отсутствуют | есть |
| Гравитация | ослабленная/левитация | обычная |
| Частицы | медленные, эфирные | пыль, искры, поток |
| Звук | эхо, тонкий ambient | плотный ambient, механика |
| NPC | инструкторы, архитекторы | операторы, курьеры |
| Время | design-time | runtime |

Это не «скин». Это разные правила чтения сцены.

## 3. Направления

| Переход | Эффект | Что чувствует пользователь |
|---|---|---|
| `M → R` | **Кристаллизация** | линии наполняются материей, цвета теплеют, появляется вес и тени, звук плотнеет, haptic «твердеет» |
| `R → M` | **Сублимация** | материя становится каркасом, цвета холоднеют, вес исчезает, звук уходит в эфир, haptic «отпускает» |

Асимметрия обязательна: направление должно читаться даже без текста и без цвета — по звуку, весу и характеру движения.

## 4. Фазы перехода

| Фаза | Длительность | Что происходит |
|---|---:|---|
| Намерение | 0.15 с | HUD: `M → R`; подсветка фокуса; лёгкий «вдох» камеры |
| Фаза | 0.55 с | радиальная кристаллическая вуаль / сублимационная рябь; смена материалов, света, физики, звука |
| Прибытие | 0.30 с | стабилизация; сигнатура мира; краткий контекст |

Итого ≈ 1.0 с.

Правила:

- переход можно пропустить после 0.3 с;
- при `reduced motion` — мгновенная смена с HUD-подсказкой, без вспышек и «дыхания» камеры;
- частота миганий ≤ 3 Гц;
- во время перехода ввод блокируется, кроме «пропустить»;
- камера не двигается, кроме опционального микросдвига FOV 1–2%.

## 5. Ввод

| Платформа | Действие | Порог |
|---|---|---|
| Desktop | удержание `Tab` | 200 мс |
| Desktop | кнопка «Фаза» в HUD | 200 мс |
| Touch | удержание кнопки | 200 мс |
| VR | удержание grip | 250 мс + haptic-импульс |

Защита:

- удержание, а не одиночное нажатие;
- кулдаун 500 мс после завершения;
- блокировка во время ввода текста, модальных окон, drag-and-drop;
- переназначаемая клавиша;
- `phase lock` для презентаций и обучения.

Почему удержание: «в любой момент» не должно означать «от случайного чиха».

## 6. Куда попадает пользователь

Правило: **переход следует за фокусом.**

| Ситуация | Результат |
|---|---|
| выбран элемент с двойником | попадаешь к двойнику |
| ничего не выбрано | остаёшься в тех же координатах, но в другом мире |
| выбран абстрактный класс | диалог выбора подкласса; отмена остаётся в M |
| двойника нет | локальная аннотация: «нет материального воплощения» / «здесь ничего не создано» |
| объект-сирота | маркер `drift`; переход к несуществующему классу не ведёт |
| выбрана связь | переход к её представлению в другом мире |

«Двойник» — не копия. Это соответствующая сущность: класс ↔ его экземпляр, объект ↔ его класс, ресурс-тип ↔ ресурс-экземпляр.

## 7. Что видно о другом мире

Только **идентичность выбранного двойника**, без сцены и live-превью:

- до перехода: `M → R · Circle`;
- после: `R — Воплощение · Circle#2`.

Запрещено:

- рендерить другой мир сквозь прозрачность;
- показывать мини-карту другого мира;
- показывать все экземпляры сразу как «превью»;
- показывать live-метрики другого мира как факт в текущем.

Разрешено:

- счётчик выбранного элемента (`2 экземпляра`);
- бейдж «нет материального воплощения»;
- история последних 10 переходов по запросу;
- хлебные крошки `M: Circle → R: Circle#2`.

## 8. Состояния перехода

```
idle
  │ holdStart
  ▼
arming (0–200 мс)
  │ holdComplete             │ holdCancel
  ▼                          ▼
intent (0.15 с)            idle
  │
  ▼
phase (0.55 с)
  │ skip                     │ complete
  ▼                          ▼
arrival (0.30 с) ◄───────────┘
  │
  ▼
idle (cooldown 500 мс)
```

Состояния:

| Состояние | Ввод | HUD | Мир |
|---|---|---|---|
| `idle` | активен | сигнатура мира | стабилен |
| `arming` | удержание | прогресс-кольцо | стабилен |
| `intent` | заблокирован | `M → R`, фокус | лёгкий сдвиг |
| `phase` | только skip | вуаль | трансформация |
| `arrival` | заблокирован | новый мир + контекст | стабилизация |
| `cooldown` | заблокирован | таймер | стабилен |

## 9. Ошибки и краевые случаи

| Случай | Поведение |
|---|---|
| переход во время загрузки модели | блокируется, HUD: «модель загружается» |
| переход во время редактирования | блокируется или сначала коммит, по настройке |
| потеря фокуса | переход к координатам, без двойника |
| двойник удалён между мирами | аннотация `drift`, остаёмся в текущем мире |
| несколько двойников (несколько экземпляров) | выбор экземпляра или «все» (агрегация) |
| абстрактный класс без подклассов | ворота материализации объясняют, что создавать нечего |
| VR: потеря трекинга | переход отменяется, haptic-сигнал |
| reduced motion | мгновенная смена, без вуали |
| screen reader | «Переход в R-мир. Выбран Circle» |

## 10. Звук и haptic

Звук — не декор, а канал направления:

- **M → R**: низкие частоты растут, появляется «удар»/щелчок кристаллизации;
- **R → M**: высокие частоты растут, звук «уходит», остаётся эхо;
- оба перехода — двухслойный sweep, не громче фонового ambient;
- звук отключаем; направление дублируется текстом и вибрацией.

Haptic:

- M → R: короткий жёсткий импульс;
- R → M: мягкий затухающий импульс.

## 11. Доступность

- `reduced motion`: без вспышек, без FOV-дыхания, мгновенная смена;
- контраст текста HUD ≥ 4.5:1;
- направление кодируется минимум двумя каналами (текст + звук/haptic/иконка);
- нет мерцания > 3 Гц;
- screen reader объявляет мир, фокус и результат;
- альтернатива удержанию — настраиваемое одиночное нажатие с подтверждением.

## 12. Мультиплеер (зарезервировано)

- у каждого пользователя своя фаза;
- чужие миры не видны;
- связи модели общие;
- конфликт редактирования решается версионированием, а не «кто первый вошёл».

## 13. Будущие миры

Правило «одно присутствие, ноль видимости» должно выдержать добавление:

- `S` — код/шейдеры/конфиги;
- `P` — физическое железо/GPU.

Для каждого нового мира нужны:

1. собственная `phaseSignature` (материал, свет, звук, физика, NPC);
2. направленные эффекты перехода;
3. правила двойников;
4. self-check.

## 14. Критерии приёмки

1. Пользователь без подсказки отвечает: «Где ты сейчас?»
2. Пользователь различает направление перехода без чтения текста.
3. Пользователь понимает, почему у призрака нет двойника.
4. Переход не ломает пространственную память: та же точка, другой мир.
5. `reduced motion` работает без потери смысла.
